# Profiles de referência

Este diretório é reservado para profiles baseados em manual real do drive.

Critérios:

- derivado de manual/documentação técnica do fabricante
- declarativo
- sem lógica no core
- sem alteração da semântica do framework
- pode servir como ponto de partida para terceiros

Observação importante:

Neste pacote ainda não foi materializado um profile manual-backed de fabricante específico,
porque nenhum manual de drive real foi anexado nesta sessão. A estrutura já está pronta
para receber o primeiro profile real sem refatorar o core.
