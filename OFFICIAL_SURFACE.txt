OFFICIAL SURFACE

This file defines the intended public-facing surface of the framework.
Anything outside this surface may be internal, experimental, or subject to change.

PUBLIC ENTRYPOINTS

- scripts/framework.sh
- scripts/diag.sh
- scripts/validate_profile.sh
- scripts/validate_driver_profile.sh

PUBLIC DIRECTORIES

- profiles/driver/
- profiles/reference/
- profiles/validated/
- hal/examples/
- hal/topology/
- hal/adapters/
- docs/

HAL STRUCTURE

- hal/core/         -> reusable semantic building blocks
- hal/core_multi/   -> reusable multi-axis semantic building blocks
- hal/topology/     -> topology composition layer
- hal/examples/     -> user-facing HAL entrypoints
- hal/adapters/     -> backend binding layer

USER MODEL

The user is expected to:

1. choose or create a driver profile
2. choose the intended topology
3. select the corresponding HAL entrypoint
4. integrate that HAL into their own LinuxCNC configuration
5. use diag.sh for runtime observability

IMPORTANT RULES

- The framework does not create INI files automatically
- The framework does not modify HAL automatically
- The framework does not depend on a machine-specific INI
- LinuxCNC configuration remains user-specific
- Gantry remains experimental

NOT PART OF THE OFFICIAL SURFACE

- machine-specific INI files
- GUI/postgui files
- local runtime artifacts
- logs/
- outbox/
- backups
- developer-only historical files
